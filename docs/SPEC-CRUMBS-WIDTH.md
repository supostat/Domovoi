# Conventions

- Видимая крошка показывает имя целиком; усекается только текущий уровень и только когда «… › текущее» не
  помещается.
- Раскладка, зависящая от ширины, пересчитывается сама при смене ширины (`setFrameSize:`), а не ждёт пересборки.

# Knowledge

- Правило (путь `Macintosh HD › Users › ingvar › Library › Caches › com.apple.Safari`):
  - всё помещается — все уровни, без «…»;
  - не помещается — уровни уходят в «…» по одному, начиная со второго, ближние к текущему держатся дольше:
    `Macintosh HD › … › Caches › com.apple.Safari`, затем `Macintosh HD › … › com.apple.Safari`;
  - всё ещё не помещается — в «…» уходит и первый: `… › com.apple.Safari`;
  - не помещается и это — текущая крошка усекается по хвосту, полный текст в `toolTip`.
  Меню «…» перечисляет свёрнутые уровни в порядке пути (диск — первым, когда свёрнут).
- Ширины — `fittingSize` кнопок (13/500, текущая 13/600, «…» 13/500) и разделителей «›» (13/400) плюс интервал
  6 pt, измеренные один раз на путь; видимый набор выбирается арифметикой, стек пересобирается только при смене
  набора.
- Экраны собираются на `WINDOW` и дотягиваются до окна пружинами; смена фокуса пересобирает экран (`show_current`),
  растягивание окна — нет. Оба пути доходят до крошек через `setFrameSize:` их растягиваемого кадра — так на
  широком окне уровни возвращаются, а при пересборке набор сразу верный. Урок сетки карточек (`CardsLayout`):
  раскладка, не реагирующая на смену ширины, остаётся в старом размере.
- Граница гейтов: тест `truncation` проходит лестницу ширин на настоящем виде крошек и шапку `MainScreen` с
  «в облаке» на самом глубоком фокусе. Не доказывает гейт: живое растягивание окна мышью — приёмка человеком:
  на глубоком пути при «в облаке» крошки не заходят под переключатель, при растягивании окна уровни возвращаются.
